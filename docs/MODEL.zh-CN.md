# Zr–Nb 教学模型说明

版本 1.0.0，2026-09-26。参数和概率是机制演示设定，除明确标注的晶格值和物理常数外均未标定。

## 三个独立模块

| 模块 | 计算内容 | 结果意义 |
|---|---|---|
| 结构演化 | 二维统计网格中的随机迁移、缺陷源和状态转换 | 学习定性机制与模型内部趋势 |
| 晶格观察 | 固定参考几何的三维投影 | 理解 HCP / BCC / FCC 原子排列 |
| XRD | 晶面间距与合成高斯峰 | 理解峰位和峰宽的几何关系 |

三个模块没有标定后的跨尺度映射。Nb 富集区只表示统计区域，不能用于推算合金成分、相分数或相图。初始材料区域在演化过程中保持固定，未模拟再结晶、晶界迁移、Nb 析出或相界面推进。

## 网格与边界

- 72 × 44 网格，每格是粗粒化的统计区域，不是一个晶格位点。
- 4、9 或 16 个随机种子生成 Voronoi 晶粒，左邻或上邻归属不同则标为晶界。
- 七个种子团簇按最近距离选取网格，构成指定面积的 Nb 富集区域。
- 所有迁移为反射边界。没有模型外氢损失、渗透穿出或气体释放。氢源只在左边界输入，初始氢分布在前 12 列。
- 所有源项的不足一个单位部分累积到下一步，避免直接取整丢失输入。

## 每步规则

先加源项，再迁移自由氢，再迁移自间隙原子，最后逐网格进行复合、晶界吸收、俘获、解俘获、析出/溶解。

### 输入

自由氢增量为 `hydrogen / 9`；缺陷对增量为 `radiation / 12`。每一对同时增加一个空位和一个间隙原子。空位生成位置与间隙生成位置相差标准差为 2 网格的高斯随机位移，并裁剪到模型边界。

- 中子和电子：均匀体源。两者在该模型中使用同一缺陷规则，未计算真实能量转移机制差异；同种子可能得到相同计数，这是简化造成的，不是两种粒子等效的结论。
- 质子：横向中心为样品宽度的 0.35、标准差为 0.10 的高斯分布；每两对缺陷额外加入 1 个氢示踪单位。没有真实停止深度或注入效率标定。
- 重离子：同一步的缺陷围绕一个共同中心产生，以表示簇状源。未求解碰撞级联、电子激发、电子阻止或离子轨迹。
- 尚无独立光子/γ 模型；电子选项不能被当作 γ 射线替代。

### 热激活迁移

`T = temperature + 273.15 K`

`m = clamp(0.32 exp[-0.12 eV / kB × (1/T − 1/573.15 K)], 0.02, 0.9)`

`kB = 8.617333262 × 10^-5 eV/K`。

自由氢以概率 m 向上下左右之一移动一格，否则留在原处。Nb 区乘 1.4，最终上限 0.95。0.12 eV、0.32 与 1.4 都是教学数值，不能引用为真实 Zr–Nb 的扩散数据。本模型各向同性，未解析 HCP 方向相关的迁移势垒。

自间隙原子以概率 `0.4 + 0.5m` 随机迁移一格，空位不迁移。这里的缺陷迁移速率也是教学设定。

### 复合与晶界汇

同格每一对空位/间隙原子以概率 `0.45 + 0.5m` 同时移除。晶界上，空位以概率 `0.008 + 0.1m` 被吸收，间隙原子以概率 `0.08 + 0.2m` 被吸收。累计复合与两类汇吸收计数单独保存。

### 可逆俘获

设 v 为空位数，B 为晶界标志（0/1），N 为 Nb 区标志（0/1）。

- 容量 `capacity = 1 + 2v + 2B + 2N`。
- 存在空位、晶界或 Nb 区时，俘获概率 `min(0.6, 0.04 + 0.06v + 0.06N)`；否则为 0。
- 解俘获概率 `0.003 + 0.045m`。
- 空位消失不会瞬时删除已俘获氢；它们按上述概率逐步释放。

以上是有效储库的简化，不是显式缺陷结合能模型；Nb 区被整体设为俘获区，而真实材料中界面与体内位点可能差异很大。

### 析出与溶解

教学阈值 `s = 2 + floor(temperature / 100)`，温度单位 °C。

- 非 Nb 网格，自由氢数 ≥ s + 3 时，以 0.24 的概率将 3 个自由氢示踪单位移到氢化物储库。
- 已有氢化物且自由氢数 < s 时，以 `0.0005 + 0.022m` 的概率将 3 个单位重新放回自由氢。
- 阈值是示踪计数阈值，不是真实固溶度。未区分 TSSp/TSSd、γ/δ/ε 动力学，不包含相场、弹性应变、应力诱导重取向或成核能垒。
- 每个紫色短片沿该晶粒的随机示意方向绘制，长度随储库氢数增长，仅用于识别；不是晶体学取向关系预测。片上的三个示踪单位不表示 ZrH3 或任何化学式。

## 守恒关系

`H_free + H_trapped + H_hydride = H_initial + H_surface_input + H_proton_input`

`V_remaining + pairs_recombined + V_sink = pairs_generated`

`I_remaining + pairs_recombined + I_sink = pairs_generated`

所有计数为非负整数。热处理阶段不重置材料，只改变条件；重建和预设重置材料。每 5 步记录一次历史，导出时也包含当前最后一步。最多 2000 步用于限定浏览器工作量，不表示达到物理稳态。

## 晶格几何与出处

- α-Zr：`a = 0.32324 nm, c = 0.51472 nm`。Kashkarov et al., Coatings 2019, 9, 31，文中初始 E110 的 α 相晶格参数。https://doi.org/10.3390/coatings9010031
- Nb：`a = 0.330 nm`。High-temperature treatments of niobium under high vacuum, dilute air- and nitrogen-atmospheres as investigated by in situ X-ray absorption spectroscopy, 2021。其计算使用 BCC Nb 的 a = 3.30 Å。https://pmc.ncbi.nlm.nih.gov/articles/PMC7842222/
- δ 氢化物：`a = 0.47776 nm`。Kudiiarov et al., Metals 2020, 10, 247，表 1 的特定氢化条件测量值。https://doi.org/10.3390/met10020247

这些值各有材料与实验背景，不组成经过统一标定的 Zr–Nb–H 数据库。BCC Nb 参考模型不表示任意 Zr–Nb 中的 β 相组成。

HCP 基矢 a1=(a,0,0), a2=(-a/2,√3a/2,0), c=(0,0,c)，基元 (0,0,0)、(2/3,1/3,1/2)。HCP 氢位采用三个 A 层原子及一个 B 层原子间的四面体几何中心位置演示。BCC 小球展示部分四面体位。FCC 模型仅在一个晶胞画出六个四面体间隙位的氢，以说明 ZrH1.5 占位；这不是有序氢配置预测。

## XRD

Cu Kα 代表波长 `λ=0.15406 nm`，忽略双线。

HCP：`1/d² = 4(h² + hk + k²)/(3a²) + l²/c²`。

立方：`1/d² = (h² + k² + l²)/a²`。

`2θ = 2 asin[λ/(2d)]`。均匀应变输入将各相所有晶格参数乘以 `1 + strain/100`；该应变不是由氢含量推算而来。

`β_L = 0.9λ/(L cosθ)`；`β_ε = 4ε tanθ`（弧度），换成角度后以平方和加 0.15° 仪器宽度。峰形为 `I(2θ)=I0 exp[-4 ln2 ((2θ−2θ0)/FWHM)^2]`。

峰强度 I0 人为设定，不计算结构因子、吸收、织构、相分数或真实仪器响应。每相曲线单独显示，没有进行 Rietveld 精修。列出的 hkl 是教学用选取的参考峰，不是完整峰表。相干衍射域尺寸不等于光学或电子显微镜的晶粒尺寸。
