# 验证记录

2026-09-26，模型 v1.0.0。

## 自动检查

- 四种粒子模式分别运行 300 步，然后关闭外源并在 600 °C 继续运行 300 步；氢与两类缺陷的收支均守恒。
- 所有氢/缺陷计数非负、为整数；氢化物储库按三单位包转换。
- 相同种子、参数与推进次数产生完全相同的结果。
- 导出的初始参数、种子和分阶段变更记录可重演完全相同的结果。
- 无氢、无辐照的初始样品不产生氢或缺陷。
- 质子模式有额外氢输入；中子模式不直接注入氢。
- 足够长的充氢情景能够触发析出。
- 均匀膨胀导致峰位向低角移动；相干域缩小和微应变增加导致峰宽增加；相开关改变参考峰列表。

## 浏览器检查

使用本机 Chrome/Playwright，以 file:// 打开入口，验证无需网络和构建过程即可运行。

通过：推进/播放/暂停、情景重建、保留历史加热、快照、CSV/JSON 实际下载、三维晶体切换、旋转按钮、XRD 相开关，以及所有标签页。没有 JavaScript 页面错误。

1440 px 桌面截图检查通过；390 和 320 px 宽度全部模块无页面横向溢出。较宽的表格在容器内横向滚动。已检查更新后的图表轴标题与手机布局。

## 检查的意义

这些检查验证软件与守恒关系；不构成物理模型验证。未与实验数据拟合或验证。仅在 Chrome 实际测试，Safari/Edge 尚未单独测试。
